# Security policy

Security-sensitive surfaces include media parsers, downloader integrations, archive and path handling, prompt injection in source content, provider credentials, and generated skill distribution.

Report vulnerabilities through GitHub's private vulnerability reporting for this repository. Do not open a public issue containing exploit details, credentials, private media, or malicious samples.

The current `0.1.x` line receives security fixes. Keep FFmpeg and yt-dlp updated even when the Python package itself has not changed.

See [the security model](docs/security.md) for trust boundaries and deployment recommendations.
