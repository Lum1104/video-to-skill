# Contributing

Contributions should preserve the boundary between deterministic evidence processing and agent-authored semantic synthesis.

## Development

```bash
uv sync --extra dev
uv run ruff format .
uv run ruff check .
uv run mypy
uv run pytest
uv run agentskills validate "$(pwd)"
```

Add unit or synthetic-media coverage for behavior changes. Normal CI must not depend on live YouTube/Bilibili responses, private cookies, paid model APIs, or copyrighted media. Use recorded metadata fixtures and media generated by FFmpeg/Pillow.

New providers should implement the smallest relevant interface (`SourceAdapter`, `Transcriber`, `OCRProvider`, or `VisionAnalyzer`) and register an entry point. Provider errors must be actionable and must not include credentials or raw response headers.

Do not commit evidence workspaces, downloaded media, transcripts, cookies, API keys, or generated third-party course content.
